# Tank Game

A simple 2D tank game built with HTML5 Canvas and JavaScript. Move an orange-and-blue tank around the playfield, stay inside the boundaries, and fire yellow bullets from the gun barrel.

## How to run

Open `index.html` in a modern web browser (double-click the file, or use **File → Open**). No build step or local server is required.

## Controls

| Input | Action |
|--------|--------|
| **W**, **A**, **S**, **D** | Move the tank (up, left, down, right) |
| **Space** | Shoot |
